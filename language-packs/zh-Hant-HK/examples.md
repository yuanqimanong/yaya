# 繁體中文（香港）教學示例

以下全屬虛構教學材料；改寫只使用各例提供的資訊。

## 1. 潤飾財務文字

輸入：本季收入為 1.2 億港元，比去年同期增加 8%。毛利率由 20% 升到 23%。公司認為需求可能回暖，但沒有提供訂單數據。

可接受：本季收入為 1.2 億港元，按年增加 8%；毛利率由 20% 升至 23%，上升 3 個百分點。公司認為需求可能回暖，但未有提供訂單數據。

不可接受：訂單強勁增長，反映需求已全面復甦。

原因：後者加入了訂單事實，又把「可能回暖」改成確定的結論。

地區補例：原文寫「軟體更新」而使用者指定香港讀者時，可改為「軟件更新」。原文引述臺灣機構的公告時，保留「軟體」。

## 2. 保留粵語書寫

輸入：「部機今朝已經整好，你哋下晝可以照常用。」

可接受（只要求潤飾）：「部機今朝已經整好，你哋下晝可以照常使用。」或不作修改。

不可接受：「該機器已於今日上午完成維修，各位下午可正常使用。」

原因：使用者沒有要求轉成書面語；後者改變了語體，也加入了「完成維修」這類原文沒有的說法。

## 3. 改寫程式碼註解

輸入：

```python
def should_retry(status):
    # 呢度好聰明咁檢查吓個狀態使唔使重試
    return status == 429
```

只把註解改為：`# 狀態碼為 429 時傳回 True，表示應該重試。`

不可接受：`# 遇到伺服器錯誤會自動重試，直至成功為止。`

原因：程式只比對一個狀態碼，本身不會執行重試，也沒有設定次數。函式與程式碼保持不變。若團隊一向以粵語寫註解，亦可只修正內容而保留粵語。

## 4. 精簡提示詞

輸入：你是業界頂尖的摘要專家。請充分發揮你的專業，只根據 {{text}} 整理三個重點，每點不超過 50 字。如果資料不足，請先問一個問題，收到回覆後再整理。

可接受：只根據 {{text}} 整理三個重點，每點不超過 50 字。資料不足時，先提出一個問題，收到回覆後再整理。

不可接受：請運用你的知識，詳細說明這份資料。

原因：後者遺漏了變數、資料來源限制、重點數目、字數與等待回覆的條件。

## 5. 學習樣稿風格

樣稿：先睇吓行唔行到。行到，再搵邊度慢。未試過嘅地方，唔好急住落結論。

可轉移的偏好：短句、清楚的先後次序、直接描述動作、保留未確定的判斷、口語化的粵語語氣。

新任務：寫一段檢查記錄檔的提示詞，使用者要求用同一語氣。

可接受：先搵出 {{log}} 入面嘅錯誤，再按出現次序列出嚟。只用記錄入面嘅資料；唔肯定嘅地方，直接講明。

不可接受：我整過幾百部伺服器，呢啲問題難唔到我。

原因：後者捏造了經歷與身分，卻沒有轉移樣稿的處理次序。
