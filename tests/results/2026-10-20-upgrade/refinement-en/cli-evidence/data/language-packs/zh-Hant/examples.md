# 繁體中文教學示例

以下均為虛構教學材料；改寫只使用各例提供的資訊。一般示例不代表完整的地區在地化驗證。

## 1. 潤飾金融文字並保留地區

輸入：本期收入為 1.2 億元，比去年同期增加 8%。毛利率由 20% 升到 23%。公司認為需求可能回暖，但沒有提供訂單資料。

可接受：本期收入為 1.2 億元，較去年同期增加 8%；毛利率由 20% 升至 23%，提高 3 個百分點。公司認為需求可能回暖，但尚未提供訂單資料。

不可接受：訂單強勁增長，顯示需求已全面復甦。

原因：後者新增訂單事實，並把可能性改成確定結論。

地區補例：只有在使用者指定臺灣用語時，才可將「更新軟件」改為「更新軟體」。未指定地區時，保留原文一致用語。

## 2. 改寫程式碼註解

輸入：

```python
def should_retry(status):
    # 這裡很智慧地檢查一下這個狀態是不是需要重試
    return status == 429
```

只將註解改為：`# 狀態碼為 429 時回傳 True，表示應重試。`

不可接受：`# 所有伺服器錯誤都會自動重試，直到成功。`

原因：程式碼只檢查一個狀態值，不執行重試，也未設定次數。函式與程式碼保持不變。

## 3. 精簡提示詞

輸入：你是頂尖的摘要專家。請發揮你的能力，只根據 {{text}} 整理三點，每點不超過 50 字。材料不足時，先問一個問題，收到答覆後再整理。

可接受：只根據 {{text}} 整理三點，每點不超過 50 字。材料不足時，先提出一個澄清問題，收到答覆後再整理。

不可接受：結合你的知識，詳細說明這份材料。

原因：後者遺失變數、來源限制、數量、字數及等待條件。

## 4. 學習樣稿風格

樣稿：先看能不能用。能用，再看哪裡慢。沒測過的地方，先別下結論。

可轉移偏好：短句、清楚的先後順序、直接描述動作、保留尚未確定的判斷。

新任務：產生檢查所給記錄的提示詞。

可接受：先找出 {{log}} 裡的錯誤。再依出現順序列出。只使用記錄中的資訊；無法確定的地方，請明說。

不可接受：我維修過上百台伺服器，這個問題難不倒我。

原因：後者捏造經歷與身分，沒有轉移樣稿的處理順序。
