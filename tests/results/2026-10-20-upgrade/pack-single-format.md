# 首次发布的单一语言包规范

2026-10-20。按用户澄清，语言包尚未公开发布，本次只保留一份首次发布规范。先前双格式设计及其测试记录是开发过程中的历史证据，不能作为当前支持矩阵。

## 当前状态

- `format_version` 固定为 `1`；核心 `version.json` 的 `pack_format` 同为 `1`。
- 核心及五个实际语言包、贡献模板的内容版本保持 `0.2.0`。
- 单一规范允许可选 `PATTERNS.md`。没有该文件时，解析结果为 `patterns: null`，普通指南与示例仍可使用。
- `schemas/language-pack.schema.json` 为唯一语言包 JSON Schema；删除此前未发布的第二份 schema。
- 包管理器只比较当前格式及 `core_major`，已删除双格式集合及针对旧格式的 `PATTERNS.md` 禁用分支。
- 保留安装、显式替换、备份、回滚和移除；这些操作更新和恢复整份包内容，不承担历史格式迁移。

同步范围：五个包与模板 manifest、模板说明、语言包规范、Skill 的包使用参考，以及包/构建测试。构建器原本通过 `packs.FORMAT` 核对核心元数据，因此随单一常量生效，无额外兼容分支。

## 验证

Windows / CPython 3.13.5：

```powershell
python -m unittest discover -s tests -p test_packs.py -v
python -m unittest discover -s tests -p test_release.py -v
```

- 包测试：47 个方法，0 失败；4 个目录链接检查因本机权限限制跳过。
- 构建测试：14 个方法，0 失败；3 个文件符号链接子用例因权限限制跳过。
- 五个实际包和贡献模板均通过唯一 schema；五个包及复制所需文件后的模板均通过本地包校验。
- 构建测试覆盖单一格式产物、搬迁后调用、哈希/字节复现、当前格式内内容更新与恢复，以及未知格式拒绝。普通包和带 `PATTERNS.md` 的包均覆盖。
- 源码与当前文档中双格式残留搜索仅命中用于拒绝未知格式的负例。

此前 `pack-upgrade.md` 和历史评测快照保持原样；本报告说明当前规范，未把旧结果改写为新规范已经验证的证据。此轮构建由测试在隔离临时目录完成，最终交付目录需由总验收重新构建。
