# 0.2 正文只读工具验收

2026-10-20；Windows 11 / CPython 3.13.5。本报告只覆盖新增正文工具；不等于编辑效果或母语审核。

## 实现

- `detect_tells.py`：中英文共 8 组字面候选，全部为 P2 弱信号。规则唯一来源 `tell_rules.json`；逐字匹配，不从语言包加载正则或执行代码。不输出作者判断、AI 概率或高置信语义结论。
- `check_rewrite.py`：比较 frontmatter、代码、链接目标和引用 ID、HTML 标签/注释、显式 ID、占位符、URL、引用块、表格、BOM。数字及已识别单位按多重集合比较。普通引号片段通过 `--protect-quotes` 保护；姓名、路径、标识符等通过 `--protect-literal` 明确保护。
- 两个 CLI 均只读文件或标准输入，UTF-8，单份输入不超过 2 MiB。JSON 为默认输出；`--json` 为兼容别名。
- detector 成功默认退出 0；只有显式 `--fail-on` 达到候选阈值才退出 1。现有规则全部 P2，因此 `--fail-on P1` 不会被现有候选触发。checker 未授权变化退出 1；无法检查或输入错误退出 2。
- `--allow` 只接受逐个类别，不支持 `all`；允许的变化仍出现在结果里。工具没有自动改写、循环改写或写回功能。

## 测试与实测

运行命令：

```powershell
python -m unittest discover -s tests -p test_detect_tells.py -v
python -m unittest discover -s tests -p test_check_rewrite.py -v
```

独立审查修复后，14 项检测器测试、21 项机械保护测试通过。覆盖 UTF-8/CRLF/BOM、标准输入、文件不变、错误退出码、输入上限、正反例、引用/代码屏蔽、增删重复保护片段、显式许可、无法解析结构，以及“数字相同但实体归属或否定改变仍会通过”的局限。

对抗性检查发现并修正了两个实现风险：包含 `:name` 的 URL/显式 ID 被内部占位符先占用后，外层保护可能遗漏；引用标签与表格分隔行的扫描存在避免不必要回溯的空间。现在先保护外层结构，并使用有界或逐次前进的扫描。保留对应边界测试。

独立审查进一步复现并修正了：HTML 注释内的围栏/表格抢先占用后导致外层注释漏保护；单列表格漏识别；URL 中的 apostrophe 被当作链接标题引号；含行内代码的 collapsed/shortcut 引用外层保护被跳过。新增原始 before/after 回归。普通跨行引文现可保护；detector 对未配对的双引号（如英寸记号）继续检测，并明确它只屏蔽已配对引号。修复这一行为时发现大量未配对引号导致重复扫描后缀，已缓存不存在的闭合符号并增加十万个引号的回归。

最终固定源码下，10,004 英文单词，5 次进程内检测中位数 **87.504 ms**，范围 **87.056–92.613 ms**。不含解释器启动、文件读取、JSON 序列化；没有把速度上限写成依赖硬件的单元测试断言。五类约十万字符对抗输入耗时 38.370–193.082 ms。最终值及源码 SHA-256 见 [prose-tools-measurements-final.json](prose-tools-measurements-final.json)；首次实现的测量保留在 [prose-tools-measurements.json](prose-tools-measurements.json)，两次测试并非严格控制性能实验，不据此宣称优化幅度。

## 明确限制

- 检测器只接收精确语言标签 `en`、`zh-Hans`；其他标签返回 `unsupported`。候选词表不是自然度评测集，不能据此声称达到精确率或误报率门槛。
- Markdown 只支持声明的保守子集。缩进块、列表内围栏、脚注、多行链接、raw HTML 块、不闭合代码等返回 `unsupported`。这是未验证，不是通过。checker 显式 `--protect-quotes` 时未闭合引号同样返回 `unsupported`；普通英文单引号有撇号歧义，不自动识别，可用显式 literal。
- 检测器主动屏蔽已识别代码、引号、引用块、表格和标记；checker 的普通引号保护是可选项。未标记的引文无法自动确认身份。
- 数字按字面值及有限的单位表比较，不能证明数字和实体的配对、否定、条件、归因、事实正确。未列入单位表的单位词需要模型或人工复核。
- 保护片段按类别比较出现顺序，不能保证它与周围段落的语义关系。`passed` 只代表这些机械检查没有发现未授权变化。
- 只在上述 Windows/Python 环境实际运行；未形成跨平台、跨版本或跨模型证据。
