# 日本語の学習用例

以下はすべて架空の学習用資料です。書き換えには、各例に示した情報だけを使います。

## 1. 金融分野の文章を整える

入力：今期の売上高は 1.2 億円で、前年同期より 8% 増えました。売上総利益率は 20% から 23% になりました。会社は需要が回復する可能性があると考えていますが、受注データは示していません。

適切：今期の売上高は 1.2 億円で、前年同期比 8% 増でした。売上総利益率は 20% から 23% へ 3 パーセントポイント上昇しました。会社は需要が回復する可能性があると考えていますが、受注データは示していません。

不適切：受注の急増により、需要の本格的な回復が確認されました。

理由：受注の増加は入力にありません。不確実な見通しを確定した事実にも変えています。

## 2. コードコメントを整える

入力：

```python
def should_retry(status):
    # ここで賢く状態を確認して再試行が必要かどうかを見ます
    return status == 429
```

コメントだけを変更：`# ステータスが 429 の場合は True を返し、再試行が必要であることを示す。`

不適切：`# サーバーでエラーが起きたら、成功するまで自動で再試行する。`

理由：コードは一つの値を判定するだけです。再試行は実行せず、回数も指定していません。関数とコードは変えません。

## 3. プロンプトの冗長な表現を減らす

入力：あなたは世界最高の要約の専門家です。その能力を十分に発揮し、{{text}} だけを根拠に、3 項目で要約してください。各項目は 50 文字以内とします。資料が足りなければ、質問を一つして、回答を待ってから要約してください。

適切：{{text}} だけを根拠に、各 50 文字以内の 3 項目で要約してください。資料が足りなければ、確認の質問を一つして、回答を待ってから要約してください。

不適切：知識を活用して、詳しく説明してください。

理由：変数、根拠の範囲、項目数、文字数、回答を待つ条件が失われています。

## 4. サンプルの文体を別の話題に使う

サンプル：まず、動くか確かめる。動くなら、遅い箇所を探す。試していないことは、まだ決めつけない。

移せる特徴：短い文、明確な順序、動作を直接示す表現、不確実性の保持。

新しい課題：ログを確認するためのプロンプトを作る。

適切：まず、{{log}} のエラーを探す。次に、出現順に並べる。ログにある情報だけを使う。判断できないことは、そのまま示す。

不適切：私は何百台ものサーバーを修理したので、必ず原因を特定できる。

理由：経歴と能力を創作しており、文体の転用にはなっていません。
