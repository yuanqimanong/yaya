# 한국어 학습용 예제

아래 내용은 모두 가상의 학습 자료입니다. 각 예제에 주어진 정보만 사용하여 고칩니다.

## 1. 금융 문장 다듬기

입력: 이번 기간 매출은 1억 2천만 원으로, 전년 동기보다 8% 늘었습니다. 매출총이익률은 20%에서 23%가 되었습니다. 회사는 수요가 회복될 가능성이 있다고 보지만, 수주 자료는 제공하지 않았습니다.

적절한 수정: 이번 기간 매출은 1억 2천만 원으로 전년 동기 대비 8% 증가했습니다. 매출총이익률은 20%에서 23%로 3%포인트 상승했습니다. 회사는 수요가 회복될 가능성이 있다고 보지만, 수주 자료는 제공하지 않았습니다.

부적절한 수정: 수주가 급증하면서 수요의 확실한 회복이 확인되었습니다.

이유: 수주 증가라는 사실을 만들었고, 가능성을 확정된 사실로 바꾸었습니다.

## 2. 코드 주석 다듬기

입력:

```python
def should_retry(status):
    # 여기서 똑똑하게 상태를 확인해서 재시도가 필요한지 봅니다
    return status == 429
```

주석만 수정: `# 상태 코드가 429이면 True를 반환하여 재시도가 필요함을 나타낸다.`

부적절한 수정: `# 모든 서버 오류를 성공할 때까지 자동으로 재시도한다.`

이유: 코드는 하나의 값을 판단할 뿐, 재시도를 수행하거나 횟수를 지정하지 않습니다. 함수와 코드는 그대로 둡니다.

## 3. 프롬프트의 빈말 줄이기

입력: 당신은 세계 최고의 요약 전문가입니다. 뛰어난 역량을 발휘하여 {{text}}만 근거로 세 항목을 작성해 주세요. 각 항목은 50자 이내로 작성해 주세요. 자료가 부족하면 질문을 하나 하고, 답변을 기다린 뒤 요약해 주세요.

적절한 수정: {{text}}만 근거로 각 50자 이내의 세 항목으로 요약해 주세요. 자료가 부족하면 확인 질문을 하나 하고, 답변을 기다린 뒤 요약해 주세요.

부적절한 수정: 당신의 지식을 활용하여 자세히 설명해 주세요.

이유: 변수, 근거 제한, 항목 수, 글자 수, 답변 대기 조건이 사라졌습니다.

## 4. 예문의 문체를 다른 주제에 적용하기

예문: 먼저 작동하는지 확인한다. 작동하면 느린 부분을 찾는다. 시험하지 않은 것은 아직 단정하지 않는다.

옮길 수 있는 특징: 짧은 문장, 분명한 순서, 직접적인 동작 설명, 불확실성 유지.

새 작업: 주어진 로그를 확인하는 프롬프트를 작성한다.

적절한 결과: 먼저 {{log}}에서 오류를 찾는다. 다음으로 나타난 순서대로 정리한다. 로그에 있는 정보만 사용한다. 판단할 수 없는 부분은 그대로 밝힌다.

부적절한 결과: 나는 수백 대의 서버를 고쳤으므로 원인을 반드시 알아낼 수 있다.

이유: 문체 대신 개인 경험과 능력을 만들어 냈습니다.
