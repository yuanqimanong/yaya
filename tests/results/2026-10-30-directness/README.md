# 0.3.1 去防御表达验证

日期：2026-10-30。目标是减少无效对比、假想反驳、防御性铺垫和重复限定，
同时保留真实范围、风险、不确定性及作者口吻。实现依据见
[调研记录](../../research/directness.md)。

## 实际改动

- `human` 默认覆盖这些上下文决策；`human/review --focus direct` 仅处理直接性问题。
- `catalog.json` 统一提供选项、帮助和解析契约；未知品牌焦点、重复选项或越界写入被拒绝。
- 中英补充原创删改与保留示例。扫描器保持原有范围，语义判断由宿主执行。
- 首轮发现删铺垫可能使说明句像命令，随后增加一条保留句子功能的要求及两条控制例。

包括上一轮尚未提交的成果。恢复脚本只处理本轮记录的精确文件，不触碰其余工作；
遇到后续修改会停止。

```text

python .yaya/directness-20261030/restore.py --scope installed --apply
```

恢复本轮源码与对应文档/产物时，使用 `--scope source`；原理相同，默认预演。
